Boirong Cash Memo — Windows Desktop (.EXE) Builder Kit
====================================================

1. Computer-e .EXE Installer Banano (Setup.exe):
   Step 1: Ei ZIP file-ti computer-e Extract korun (Right-click -> Extract All).
   Step 2: Apnar computer-e Node.js na thakle https://nodejs.org theke LTS install korun.
   Step 3: Folder-er bhetore "BUILD_EXE.bat" file-e Double-click korun.
   Step 4: Build sesh hole "dist" folder-e "boirong-cash-memo-Setup-1.0.0.exe" paben.
   Step 5: Oi .exe file-ti double-click kore computer-e install korle Desktop & Start Menu icon chole ashbe!

2. Portable .EXE banate chaile:
   Folder-e Shift + Right Click -> "Open in Terminal" -> likhun:
   npm run build:portable
